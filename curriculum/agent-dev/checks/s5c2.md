## 这一章的项目：写一条记忆，再按用处捞回来

正文「动手练」第 1、2 题。在 `main.py` 里写两个函数。

**一、追加**

```python
def append_memory(path: str, content: str, usage: list) -> dict:
    ...
```

把一条记忆**追加**到 `path`（一行一个 JSON 对象），返回写进去的那条。每条至少要有：

```python
{"content": "让模型帮你改代码时，必须用 black 格式化",
 "usage": ["code", "format"],
 "timestamp": "2026-11-20T10:00:00"}
```

追加是重点：用 `"w"` 打开会把上一条覆盖掉。

**二、按用处捞**

```python
def search_memories(path: str, tag: str) -> list:
    ...
```

读出所有 `usage` 里含 `tag` 的条目，按写入顺序返回它们的 `content`。
文件里的空行要跳过——手工编辑 jsonl 时末尾多一个换行是常态。

**两个容易踩的点**

- `usage` 是列表，不是字符串：`"usage": "code"` 用 `in` 判断会命中
  `"code"` 的子串（比如 `"code-format"`），也会在 `"code"` 上碰巧成立，
  但写成 `["code", "format"]` 才是正文的格式。
- 追加要加 `\n`：`json.dump` 到同一个文件对象里不加分隔，两行会粘成一行。

**验收会检查什么**：连写两次是 2 行、字段齐全、时间戳存在；按 `code` 能捞出
两条且顺序对；文件里有空行也能读；另外单独检查你自己那份 `memories.jsonl`
里确实有一条 `usage` 含 `code`（正文第 1 题的手工产物）。
