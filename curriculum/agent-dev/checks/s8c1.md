## 这一章的项目：从一条失败日志里抽一道题

正文「动手练」第 2、3 题。在 `main.py` 里写：

```python
def extract_test_case(log: dict) -> dict:
    ...
```

输入一条日志：

```python
{"input": "把这段同步请求改成异步",
 "output": "import requests\nresp = requests.get(url)",
 "expected_output": "应该用 aiohttp 或 httpx.AsyncClient",
 "error": "TimeoutError: 请求超过 30 秒"}
```

输出一道题，**四个键一个都不能少**：

```python
{"input": "把这段同步请求改成异步",
 "expected_output": "应该用 aiohttp 或 httpx.AsyncClient",
 "actual_output": "import requests\nresp = requests.get(url)",
 "failure_reason": "TimeoutError: 请求超过 30 秒"}
```

注意字段改名：日志里的 `output` → 题里的 `actual_output`，`error` → `failure_reason`。

**还要交一份 `test_cases.json`**

第 3 题要求把抽出来的题加进这个文件，最外层是数组：

```json
[{"input": "...", "expected_output": "...", "actual_output": "...", "failure_reason": "..."}]
```

**两个容易踩的点**

- 缺字段用空串补：真实日志里一堆没有 `expected_output` 的老记录，
  一个 `log["expected_output"]` 就会让整批抽取停在第一条。
- 不要修改传进来的 `log`：抽题是只读操作，改了会污染后面按 id 回查的日志。

**验收会检查什么**：完整日志抽出四个字段且映射正确、缺字段补空串不报错、
传进去的字典没被改、`test_cases.json` 是非空数组且每项四键齐全。

第 1 题（翻日志找 3 条）没有产物，不在这里验。
