## 这一章的项目：算余弦，再按相似度排序

正文「动手练」第 1、2 题。在 `main.py` 里写两个函数。

```python
def cosine(a: list, b: list) -> float:
    ...

def rank_by_similarity(texts: list, query: str, embed) -> list:
    ...
```

- `cosine`：两个向量的余弦相似度，返回 -1 ~ 1 的浮点数；
- `rank_by_similarity`：把 `texts` 每一条用 `embed` 变成向量，和 `embed(query)`
  比相似度，**从高到低**返回原始下标（`list[int]`）。

**`embed` 是参数，不要自己加载模型**：

```python
def rank_by_similarity(texts, query, embed):
    target = embed(query)
    scored = [(i, cosine(embed(t), target)) for i, t in enumerate(texts)]
    scored.sort(key=lambda pair: pair[1], reverse=True)
    return [i for i, _ in scored]
```

真实使用时：

```python
from sentence_transformers import SentenceTransformer
model = SentenceTransformer("all-MiniLM-L6-v2")
rank_by_similarity(texts, query, lambda text: model.encode(text).tolist())
```

**为什么验收不装模型**：`sentence-transformers` 几百 MB，验收环境没有。
这一章的重点是「向量就是数字，比大小就完了」——向量从哪来是下一章的事。

**两个容易踩的点**

- 零向量：`[0, 0]` 和谁都不像，但也**不能除零崩掉**，返回 `0.0`。
- 返回的是下标，不是文本：`[0, 1, 3, 4, 2]` 对应原文顺序，调用方要靠它回去取。

**验收会检查什么**：四种余弦情形（同向 1、垂直 0、反向 -1、零向量不崩）、
两组文本的排序、下标不重不漏。第 3 题（换多语言模型）要下载权重，不在这里验。
