## 这一章的项目：写一段「模型擅自记错事」的对话

这一章不写代码。正文「动手练」第 3 题要求：

> 写一段 3 行的 user message + model response，展示模型「擅自记下错误事实」的
> 典型行为（比如把 Stack Overflow 回答里的假设当结论）。存成
> `bad_memory_example.md`。

**文件长这样**（格式不严格，但这三样都要有）：

```
user: 帮我查下 FastAPI 的 CORS 怎么配。
model: 根据搜索结果，加 allow_origins=["*"] 就行。我已记住这条规则。
假设：你的接口是完全公开的（搜索里那句话没说这一点，模型却把它当成了结论）。
```

**三个必须出现的要素**

1. `user` / `model` 两行，看得出谁说的；
2. 模型那句里有「记住 / 记下 / 已存」——这一题要演示的就是「擅自记下」；
3. 有一段说明点出「假设 / 可能 / 据说」——那句没验证的前提是从哪来的。

**为什么要求第 3 点**

只写一段普通对话证明不了什么。这一题的价值在于让人看见：模型说"我记住了"
的时候，记住的可能是上文里一句没人验证过的猜测。等下次它拿这条记忆去改代码，
错误就已经变成"事实"了。

**验收会检查什么**：文件存在、至少 3 行非空、同时出现「记住/记下」类和
「假设/可能」类词、标出了 user/model。不检查你写得像不像，只看这三样在不在。
