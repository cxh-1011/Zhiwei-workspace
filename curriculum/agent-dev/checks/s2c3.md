正文「动手练」第 1、3 题。在 `main.py` 里写两个函数。

**一、提取**

```python
def extract_json(text: str) -> dict:
    ...
```

从模型回复里找出那个 `{...}`，`json.loads` 之后返回字典。要能处理：

- 纯 JSON；
- 被 ```` ```json ```` 包起来的；
- 前后带「好的，结果如下」「还需要别的城市吗？」这种解释文字；
- 带缩进和空行的多行 JSON。

**找不到 JSON 时返回 `None` 或抛异常**，不要返回 `{}`——空字典在
`data["city"]` 上会 KeyError，错误会飘到两步之外。

**二、验字段**

```python
def validate_weather(data: dict) -> bool:
    ...
```

规则（正文第 1 题的要求）：

- `city` 是非空字符串；
- `temperature` 是 `int` 或 `float`——`"25"` 这种字符串不算；
- `unit` 只能是 `"celsius"` 或 `"fahrenheit"`。

**两个容易踩的点**

- `bool` 是 `int` 的子类：`{"temperature": True}` 会通过 `isinstance(x, int)`，
  想严一点就显式排除 `bool`；
- 别再对 `data` 做一次 `json.loads`：`extract_json` 已经解析过了。

**验收会检查什么**：四种包装都能提出同一个对象、七种字段组合全判对、
没有 JSON 时不返回空字典。返回值必须是布尔，不是字符串。
