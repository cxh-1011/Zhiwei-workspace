## 这一章的项目：写一个规则判分函数

在 `main.py` 里写一个函数：

```python
def price_check(text: str) -> bool:
    ...
```

判断一句话是不是「含『元』字，并且元字前面紧挨着数字」的价格描述。

**必须判对的九个例子**

| 输入 | 期望 |
|---|---|
| `总价3999元` | True |
| `价格：99元` | True |
| `单价 0.5元` | True |
| `3999` | False |
| `元` | False |
| `99块` | False |
| `九十九元` | False |
| `元3999` | False |
| 空字符串 | False |

**两个容易踩的点**

- 返回 `True`/`False`，不要返回字符串 `"True"`——它在 `if` 里永远为真，
  而你的判断逻辑看起来完全正确。
- 中文数字（`九十九元`）不算：这一题只做「数字 + 元」。正则里用 `\d`，
  不要用 `\w`。

**验收会检查什么**：九条全判对，并且返回值确实是布尔类型。
