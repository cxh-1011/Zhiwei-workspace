## 这一章的项目：写一个 parse_react()

在 `main.py` 里写一个函数：

```python
def parse_react(text: str) -> dict:
    ...
```

输入一段 ReAct 风格的文本，返回三个键：

```python
{"thought": "...", "action": "...", "action_input": "..."}
```

**要能扛住的输入**

```
Thought: 用户想知道明天上海的天气，需要查实时数据
Action: search
Action Input: Shanghai weather tomorrow
```

- 标签大小写混用（`THOUGHT:` / `action input:`）要认；
- 标签和值之间多几个空格、前后有空行，要认；
- `Action Input` 跨多行（比如一段 JSON）要完整保留，不能只取第一行；
- 缺某个字段时，那一项返回空字符串，**不要抛 KeyError**——这个解析器是要放进
  循环里的，拿到半截输出就崩会让整轮对话断掉。

**验收会检查什么**：上面四条各是一项，全过才算过。第 3 题那个 `run_react_loop`
不用写，它需要调模型，验收里跑不了。
