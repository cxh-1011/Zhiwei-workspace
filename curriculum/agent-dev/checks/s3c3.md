## 这一章的项目：解析参数，先验再调

正文「动手练」第 1、2 题。在 `main.py` 里写：

```python
def parse_arguments(raw, required=("city",)) -> dict:
    ...
```

- `raw` 是模型给的 `arguments`：可能是字符串（`'{"city": "北京"}'`），也可能
  已经被 SDK 解析成字典；
- `required` 是这一轮必须出现的参数名；
- 合法就返回**解析后的字典**；
- 不合法就**抛 `ValueError`**——缺字段、字段是空串、JSON 坏掉，都算不合法。

**用法**

```python
try:
    args = parse_arguments(call.function.arguments)
except ValueError as exc:
    print("参数不合格，重发一次：", exc)
else:
    print(get_weather(**args))
```

**两个容易踩的点**

- 别返回 `None` 表示失败：下一行 `get_weather(**None)` 会炸出一个和参数
  毫无关系的 TypeError，排查时根本想不到是这里。
- `required` 是参数，不是常量：写死成 `["city"]` 的话，换成
  `query_express` 那张表就验不出缺单号了。

**验收会检查什么**：三种合法输入（字符串、带多参数、已经是字典）都能解析；
五种坏输入（缺字段、空串、单引号、截断、空字符串）都会报错；把 `required`
改成两个字段时，只给一个的输入也要报错。
