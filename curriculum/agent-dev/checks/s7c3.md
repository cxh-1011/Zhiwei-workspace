## 这一章的项目：危险工具先停下来问人

正文「动手练」第 1、2、3 题。在 `main.py` 里写两个函数。

```python
def needs_approval(tool: dict) -> bool:
    ...

def resume_after_approval(tool_call: dict) -> str:
    ...
```

**一、要不要停**

`tool` 长这样：

```python
{"name": "delete_user_data", "description": "删除用户数据", "is_dangerous": True}
```

有 `is_dangerous: True` 就返回 `True`，否则 `False`。

**二、批了之后怎么执行**

`tool_call` 是模型给的那条：

```python
{"id": "call_1", "type": "function",
 "function": {"name": "delete_user_data", "arguments": '{"user": "u789"}'}}
```

解析 `arguments`，返回一句执行结果，**必须同时含「已执行」和参数里的 `u789`**：

```
已执行：删除用户 u789 数据
```

**两个容易踩的点**

- 参数解析不了时不要返回「已执行」：那等于把一次没跑成的操作记成了成功。
  抛异常或者返回一句失败提示都行。
- 两处都要解析 `arguments`：`needs_approval` 之后参数还在那条 tool_call 里，
  `resume_after_approval` 要自己再解析一遍，别指望上一轮留下的变量。

**验收会检查什么**：三种工具的审批判断（危险 / 普通 / 显式 False）、
审批后返回值含「已执行」和用户 id、参数是半截 JSON 时不假装成功。
