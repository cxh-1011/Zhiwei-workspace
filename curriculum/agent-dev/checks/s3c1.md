## 这一章的项目：手写一条 tool_call

新建一个文件 `tool_call.json`，把你"扮演模型"输出的那条工具调用存进去。

**格式要求**

- 顶层是一个对象，至少有 `name` 和 `arguments` 两个字段；
- `name` 是函数名的字符串，比如 `"get_weather"`；
- `arguments` 必须是**字符串**，里面是被转义的 JSON 文本：

```json
{"name": "get_weather", "arguments": "{\"city\": \"杭州,苏州\"}"}
```

`arguments` 里要有 `city`，值是字符串（`"杭州和苏州"` 或 `"杭州,苏州"` 都算对）。

**验收会检查什么**

1. 文件能 `json.loads`；
2. 有 `name` 和 `arguments`；
3. `arguments` 是字符串而不是对象——正文第 3 题那两处错，根子就在这里；
4. 把 `arguments` 再解析一次，`city` 是字符串。

**为什么这么较真**：真实接口里 `arguments` 一旦写成嵌套对象，模型返回的第
二轮会解析失败，而错误信息只说"invalid JSON"，看不出是自己手拼引号拼错了。
