## 这一章的项目：揪出资料里没有的函数名

正文「动手练」第 1、2 题。在 `main.py` 里写：

```python
def find_unsupported(answer: str, sources: list) -> list:
    ...
```

- 从 `answer` 里找出所有**函数调用**（带括号的标识符，比如 `result()`、
  `future.result()`、`as_completed()`）；
- 逐个看它在不在 `sources` 拼起来的文本里；
- 不在的收集起来返回，**同一个名字只报一次**，保持出现顺序；
- 都在就返回空列表。

**为什么只查函数调用**

中文答案里的普通词没法可靠对比（同义词、语序都在变），但 `foo()` 这种带括号
的标识符是硬信号：它要么在资料里，要么就是编的。这也是正文第 2 题让人
"标出第一个不在原文里出现的动词"的可执行版本。

**会撞上的例子**

```python
answer = "先用 submit() 提交任务，再用 future.result() 取结果。"
sources = ["ThreadPoolExecutor.submit() 提交单个任务，返回 Future 对象。"]
# → ["future.result"]   # submit 在资料里，result 不在
```

**两个容易踩的点**

- 别把「Future」和「future.result」混为一谈：前者是类名（资料里有），
  后者是方法调用（资料里没有）。按完整标识符比，不要把点号后面那段单独拆出来。
- 只认带括号的：`Future 对象` 没有括号，不该被当成函数调用去查。

**验收会检查什么**：能报出 `result()`、不误报 `submit()` / `as_completed()`、
没有函数调用时返回空、同一个名字只报一次。第 3 题（改提示词治乱编）要调模型，
不在这里验。
