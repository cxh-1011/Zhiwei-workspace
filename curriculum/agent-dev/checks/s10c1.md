## 这一章的项目：算清一段文本花多少钱

正文「动手练」第 1、2 题。在 `main.py` 里写两个函数。

**一、单个模型**

```python
def count_gpt_cost(text: str) -> float:
    ...
```

返回 GPT-4o-mini 处理这段文本的预估费用（美元）。价格按正文给的：
**输入 $0.15 / 1M token**。

**二、两个模型对比**

```python
def compare_cost(text: str) -> dict:
    ...
```

返回：

```python
{"gpt-4o-mini": 0.0000123, "claude-3-haiku-20240307": 0.0000205}
```

两个值必须**不一样**——两家的价格本来就不同。

**token 数可以粗估**

```python
def count_gpt_cost(text):
    tokens = max(1, len(text) // 4)      # 英文粗估；中文可以按 len(text) 算
    return tokens / 1_000_000 * 0.15
```

真实项目里请用 `tiktoken`。验收不装它（要联网下载词表），所以只要你的估算
**随文本变长而变大**、量级对得上就行。

**两个容易踩的点**

- 别把「每百万 token $0.15」写成「每千 token $0.15」：差 1000 倍，
  一个月下来账单会告诉你。
- 别忘了除：`tokens / 1_000_000 * price`，不是 `tokens * price`。

**验收会检查什么**：短文本算出一个小正数（不到 1 美分）、文本长了费用跟着涨、
两个模型的价格不相同且都是正数。第 3 题（拿真实代码跑一遍）没有固定产物，
不在这里验。
