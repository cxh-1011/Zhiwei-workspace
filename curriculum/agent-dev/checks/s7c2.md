## 这一章的项目：取消之后把临时文件清掉

正文「动手练」第 1 题。在 `main.py` 里写一个类：

```python
class TempFlag:
    def __init__(self, path): ...
    def start(self): ...      # 写文件，内容 "running"
    def cancel(self): ...     # 删文件
```

**在真实代码里的用法**

```python
flag = TempFlag("/tmp/agent_temp.txt")
flag.start()
try:
    await ask_slowly()
finally:
    flag.cancel()          # 不管是正常结束、异常、还是被取消，都会走到
```

用 `finally` 而不是 `except CancelledError`：正常结束时临时文件同样该删掉。
正文那一版写在 `except asyncio.CancelledError` 里，是为了让你先看清"取消走的是
哪条分支"，实际项目里 `finally` 更稳。

**两个容易踩的点**

- `cancel` 要能重复调用：用户连点两次"停止"是常态，第二次文件已经不在了。
  用 `os.path.exists` 判断，或者 `except FileNotFoundError: pass`。
- 没 `start` 就 `cancel` 也不能炸：异常发生在 `start` 之前时，`finally` 里
  照样会调 `cancel`。

**验收会检查什么**：`start()` 之后文件存在且内容是 `running`、`cancel()`
之后文件不存在、连续调两次 `cancel()` 不抛、没 `start` 就 `cancel` 不抛。

第 2 题（`timeout=2.0` 抛 `APITimeoutError`）要真发请求，不在这里验。
