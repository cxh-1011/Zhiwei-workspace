## 这一章的项目：拼装四段式提示词，并找出缺的那一段

正文「动手练」第 1、2 题。在 `main.py` 里写两个函数。

**一、拼装**

```python
def build_prompt(role: str, task: str, constraints: str, output_format: str) -> str:
    ...
```

把四个参数拼成一段提示词，**四段都要有小标题**，顺序是
角色 → 任务 → 约束 → 输出格式。比如：

```
## 角色
资深后端工程师，专做支付系统
## 任务
把这段同步调用改成 asyncio 并发
## 约束
不要改变函数签名；失败要重试两次
## 输出格式
只返回改完的代码，不要解释
```

小标题用 `##`、`**角色**`、`角色：` 都行，验收只认「角色」这两个字出现过。

**二、找缺失**

```python
def find_missing_section(prompt: str) -> str:
    ...
```

返回缺失的段名，就是 `"角色"` / `"任务"` / `"约束"` / `"输出格式"` 之一；
四段齐全时返回**空字符串**。

**注意**：验收给的提示词里，四段都是「角色：…」「任务：…」这种显式标注，
不会是「你是资深工程师，帮我…」。因为判分靠这四个词定位，没有标注就无从下手。

**两个容易踩的点**

- 返回值别带多余的话：返回 `"缺少约束段"` 能过（判分用的是「包含」），
  返回 `None` 不行。
- 四段齐全时必须有「什么都不缺」的出口，否则每一段都会被报缺。

**验收会检查什么**：拼出来的文本含四个段标题、四段内容都在、顺序递增；
三段各缺一段的提示词都能指出缺哪段；四段齐全时返回空串。
