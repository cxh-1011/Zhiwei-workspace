## 这一章的项目：把两版结果并排看，找出行为变了的题

正文「动手练」第 3 题。在 `main.py` 里写：

```python
def compare_results(old: list, new: list) -> list:
    ...
```

`old` / `new` 各是一组结果，每条：

```python
{"question": "查上海天气", "content": "", "tool_calls": [{"name": "get_weather"}]}
```

返回**差异列表**，每项：

```python
{"question": "查上海天气", "changed": ["tool_calls"]}
```

`changed` 里只用两个词：`"tool_calls"`（调没调工具变了）、`"content"`（回答内容变了）。
两版一样就不出现在结果里。

**还要交三份文件**

| 文件 | 内容 |
|---|---|
| `regression_questions.txt` | 正文第 1 题的 5 道题，**正好 5 行**，一行一道 |
| `old_results.json` | 旧提示词的 5 条结果，每条含 `question` |
| `new_results.json` | 新提示词的 5 条结果，每条含 `question` |

**两个容易踩的点**

- 只比 `content` 会漏掉最严重的一类回归：**新提示词不再调工具了**。
  这时 `content` 里通常是一段"我自己编的答案"，看起来还挺通顺。
- 新版少一道题时别 `IndexError`：按 `question` 配对，而不是按下标配对。

**验收会检查什么**：两处变化（一处丢工具、一处内容变）都能找出来、
没变化时返回空列表、新旧数量不同也不崩、三份文件齐全且行数/条数是 5。

第 2 题要真调两次模型，不在这里验。
