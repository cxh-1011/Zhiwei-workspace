## 这一章的项目：切两半、数 token、查上限

正文「动手练」第 2、3 题合成一个项目。在 `main.py` 里写：

```python
def split_and_count(text: str, encode) -> tuple:
    ...
```

- 把 `text` 从**中间**切成前后两半；
- 用传进来的 `encode` 分别数两半的 token，再数一遍全文；
- 返回 `(前半数, 后半数, 总数)`，三个都是整数。

**`encode` 是参数，不要在函数里 import tiktoken**：

```python
def split_and_count(text, encode):
    half = len(text) // 2
    head, tail = text[:half], text[half:]
    return len(encode(head)), len(encode(tail)), len(encode(text))
```

真实使用时这样调用：

```python
import tiktoken
enc = tiktoken.get_encoding("cl100k_base")
print(split_and_count(long_chat, enc.encode))
```

**两个容易踩的点**

- 别把总数除以二当答案：验收会换一种 `encode` 再跑一次，除二算出来的
  值对不上。
- 切点落在两半中间时，前半和后半都不能为空。

## 还要交一份 `context_limit.md`

第 3 题让你查所用模型的上下文上限，写成一行：

```
gpt-4-turbo: 128,000 tokens
```

数字带不带逗号都行，`32k tokens` 也认。

**验收会检查什么**：三种情形各一次——每字符一 token 时两半之和等于全长、
每 3 字符一 token 时误差不超过 2、`context_limit.md` 里读得出一个大于 4000 的上限。
