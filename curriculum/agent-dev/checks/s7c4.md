## 这一章的项目：从日志里回放一条链路

正文「动手练」第 3 题。在 `main.py` 里写：

```python
def replay_trace(trace_id: str, log_file: str) -> list:
    ...
```

- 读 `log_file`，一行一个 JSON（正文第 1 题要求的那种格式）；
- 只留 `trace_id` 匹配的行；
- **按 `ts` 升序**返回原始事件字典的列表；
- 半截的坏行跳过，不要整份日志读不了；
- 文件不存在返回空列表。

**日志长这样**

```json
{"ts": "2026-11-20T10:00:00", "trace_id": "test-123", "step": "parse_args", "status": "ok"}
{"ts": "2026-11-20T10:00:01", "trace_id": "test-123", "step": "read_file", "status": "error", "error": "No such file"}
```

**两个容易踩的点**

- 别只按文件顺序：并发跑的时候，后写的行可能是更早发生的事。验收里第一条
  日志的时间戳比第二条晚，只按文件顺序会排反。
- 别假设每行都能 `json.loads`：进程被杀时最后一行一定是半截的。用
  `try/except json.JSONDecodeError: continue`。

**验收会检查什么**：两条记录按时间升序、末尾半截 JSON 被跳过、无匹配返回空列表、
文件不存在返回空列表（而不是抛 `FileNotFoundError`）。

第 1 题（换 `jsonlogger`）要装第三方包、第 2 题（`run_step` 超时）在 Windows
上没有 `signal.alarm`，都不在这里验。
