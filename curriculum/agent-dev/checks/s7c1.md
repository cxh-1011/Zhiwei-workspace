## 这一章的项目：把流式块一块块送出去

正文「动手练」第 3 题。在 `main.py` 里写：

```python
def relay(chunks, sink) -> int:
    ...
```

- `chunks` 是任意可迭代对象，每次给一个字符串片段（真实的 SDK 给的生成器）；
- 每拿到一块就调一次 `sink(piece)`；
- 空字符串和 `None` 跳过，不往下送；
- 返回**总字符数**。

**为什么不直接 `print`**：这一题的重点是「送出去的动作发生在每收到一块的时候」。
`relay` 把"写到哪里"变成了参数，命令行传 `print`，网页传 `sink`，
写文件传 `f.write`，同一段逻辑三处复用。

**对照正文那段**

```python
for chunk in stream:
    piece = chunk.choices[0].delta.content
    if piece:
        relay_one(piece)      # 这里就是 sink(piece)
```

**两个容易踩的点**

- 别先 `"".join(chunks)` 再 `sink(整段)`：验收会数 `sink` 被调了几次，
  一次就说明攒起来了。用户看到的效果是转半天然后一次性弹出全文。
- `delta.content` 可能是 `None`（工具调用轮次就没有正文），直接
  `sink(None)` 会在 `f.write` 那里炸掉。

**验收会检查什么**：三块要调 `sink` 三次、内容顺序对、返回值是总字符数；
空块和 `None` 跳过；生成器输入也逐块处理。
