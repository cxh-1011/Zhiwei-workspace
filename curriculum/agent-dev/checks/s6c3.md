## 这一章的项目：按阈值筛一遍，再取前三

正文「动手练」第 2、3 题。在 `main.py` 里写：

```python
def top_k(ranked: list, k: int = 3, threshold: float = 0.0) -> list:
    ...
```

- `ranked` 是已经按相似度排好的 `[(文本, 分数), ...]`；
- 先筛掉分数 `<= threshold` 的，再取前 `k` 条；
- **原样返回**里面的元素，不要重新组装成字典或字符串——下游还要用分数做展示。

正文那行是：

```python
ranked = [(t, s) for t, s in ranked if s > 0.6]
```

**为什么把阈值做成参数**

查代码要 0.6，查闲聊 0.4 才够。写死 0.6 的实现，换一个语料就得改代码。

**还要交一份 `reranked_chunks.json`**

第 3 题要求把 top3 存下来：

```json
{"chunks": ["猫对咖啡因极度敏感，少量就会中毒。", "咖啡因在肝脏中代谢，猫缺乏相关酶。"]}
```

1~3 条都行（过了阈值可能不足 3 条），每条是非空字符串。

**两个容易踩的点**

- `k` 是**上限**，不是目标：只有 2 条过阈值就返回 2 条，不要补空串占位。
- 筛完不要重新排序：上游已经排好了，重排会把「原顺序」这个信息弄丢。

**验收会检查什么**：0.6 阈值下只留两条、`k` 当上限用、空输入返回空列表、
顺序不变、`reranked_chunks.json` 结构正确。
