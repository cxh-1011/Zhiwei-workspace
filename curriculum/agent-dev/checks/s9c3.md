## 这一章的项目：一张「现在别硬刚」的红灯清单

这一章不写代码。正文「动手练」第 3 题：

> 新建 `agent_limits.md`，写下三条红灯项，格式如
> `🔴 实时查未公开数据库 —— 它没权限，也没连接方式。`

**要求**

- **正好 3 条**，每条以 `🔴` 开头；
- 每条后面接一句原因，说明为什么现在做不了（没权限 / 没接口 / 没有稳定数据源 /
  成本不划算……）；
- 不要写「未来可能会做」这种规划，这一题要的是**当下做不了**的清单。

**例子**

```
🔴 实时查未公开数据库 —— 它没权限，也没有连接方式。
🔴 保证 2024 年前的新闻都准确 —— 训练数据有截止时间，检索源也覆盖不全。
🔴 替用户下单付款 —— 涉及资金操作，必须人工确认，不能交给模型。
```

**为什么必须正好三条**

写成十条，说明还没分清哪些是真做不了、哪些只是麻烦；写两条，说明漏了。
三条这个数刚好逼你排一遍序：最不可能绕过去的那三个是哪三个。

**验收会检查什么**：文件存在、带 🔴 的行正好 3 行、每行足够长（看出写了原因，
不是只写了个名字）。
