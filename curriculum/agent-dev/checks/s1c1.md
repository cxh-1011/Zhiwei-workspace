## 这一章的项目：算出中英文各占多少 token

在 `main.py` 里写一个函数：

```python
def compare_tokens(zh: str, en: str) -> dict:
    ...
```

输入同一段意思的中文和英文，返回：

```python
{"zh": 31, "en": 24, "diff_pct": -22.6}
```

- `zh` / `en`：估算出的 token 数，**正整数**；
- `diff_pct`：英文比中文多（或少）百分之几。负数表示英文更省。

**估算规则你自己定**，验收不检查具体数字，只检查它像不像在真的数 token。
常见的粗估：中文一个字约 1 个 token，英文四个字符约 1 个 token。
真实项目里请用 `tiktoken`——这一章的验收刻意不依赖它，因为它第一次用要联网
下载词表，验收环境没有网。

**两个容易踩的点**

- 不要用 `len(text)` 当 token 数：中文 30 个字和英文 80 个字符会被算成
  「英文更多」，和正文的结论正好相反。验收会拿这段英文来试。
- 百分比别把正负号搞反：`(en - zh) / zh * 100`。

**验收会检查什么**：两组中英文各算一次，`zh` / `en` 是正整数、英文那组确实
更省 token、`diff_pct` 和 (英文−中文)/中文 对得上（容差 1.5，也接受以英文
为分母的算法）。
