## 这一章的项目：切句子，别把话切成两半

正文「动手练」第 1、2 题。在 `main.py` 里写两个函数。

**一、切**

```python
def split_by_sentence(text: str) -> list:
    ...
```

边界有三类：

1. 句末标点 `。！？!?`；
2. 换行；
3. 分号 `；;`。

**冒号要分情况**——这是第 1 题的难点：

- `第一步：` `第 3 条：` 这类**序号标记**后面要断开；
- 冒号后面紧跟空格 / 换行 / 结尾，也要断开；
- `价格：12元` `库存：3件` 这种句内冒号**不切**。

正文给的标准答案：

```
"第一步：打开电源；第二步：按下启动键。"
→ ["第一步：", "打开电源；", "第二步：", "按下启动键。"]
```

**二、判完整**

```python
def is_complete_sentence(sentence: str) -> bool:
    ...
```

非空、结尾是句末标点、且除了标点之外至少还有一个字符。

- `"你好！"` → `True`
- `"你好"` → `False`
- `"。"` → `False`（只有标点，没有内容）
- `"价格：12元"` → `False`

**两个容易踩的点**

- 切完别留空串：`"a。。b"` 中间会切出一个 `""`，放进检索会变成一条空文档。
- 切点不要吃掉标点：`"你好！"` 的 `！` 要留在句子里，去掉之后
  `is_complete_sentence` 就会判它不完整。

**验收会检查什么**：三种常规文本（句末标点、换行、空串）、正文那个步骤例子、
句内冒号不切、六个完整性样例。
