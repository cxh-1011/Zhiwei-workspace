## 这一章的项目：给少样本示例做一次体检

正文「动手练」第 2、3 题。在 `main.py` 里写：

```python
def is_clean_example(example: dict) -> bool:
    ...
```

`example` 长这样：`{"input": "上海今天几度？", "output": "22℃"}`。
干净返回 `True`，会带坏模型返回 `False`。

**什么算脏**（正文列的三条）

1. 输出里混进了没要求的额外信息——气温之外还报了湿度、穿衣建议、适宜度；
2. 输出里带括号注释，比如 `See you next week（正式场合，不要用 see ya）`；
3. 输出里带指令，比如 `请翻译成正式英语：Hello`。

**可执行的判据**（验收就按这个，不用猜）

- 输出长度超过输入的 **2.5 倍** → 判脏（第 1 类）；
- 输出里有 `（）` 或 `()` 包起来的内容 → 判脏（第 2 类）；
- 输出里出现「请翻译」「请注意」「不要」「必须」这类词 → 判脏（第 3 类）。

**两个容易踩的点**

- 别把「英文输出」当成脏：`temperature of Shanghai today` → `22` 是干净的；
- 别只判长度：第 2、3 类脏示例的输出并不长，漏了括号和指令就会放过它们。

**验收会检查什么**：三个干净示例全判干净、三个坏示例全判脏，并且返回值
必须真的是布尔（`return "干净"` 这种字符串在 `if` 里永远为真）。
