## 这一章的项目：把函数签名翻译成 parameters

正文「动手练」第 2、3 题。在 `main.py` 里写两个函数。

**一、有默认值的参数**

```python
def get_weather_parameters() -> dict:
    ...
```

对应 `def get_weather(city: str, unit: str = "c") -> dict`，返回它的
`parameters` 部分：

```python
{
    "type": "object",
    "properties": {
        "city": {"type": "string", "description": "城市名"},
        "unit": {"type": "string", "enum": ["c", "f"]},
    },
    "required": ["city"],
}
```

要点：`unit` 有默认值 `"c"`，所以**不在 required 里**；它的取值范围只有两个，
所以要有 `enum`。

**二、连长度范围一起写**

```python
def query_express_schema() -> dict:
    ...
```

对应 `def query_express(number: str, carrier: str)`，返回**完整**的 function schema：

- `name` 是 `"query_express"`；
- `description` 要让模型知道「只有用户明确说了单号和快递公司时才用」；
- `number`：`type` 是 `string`，`minLength` 10、`maxLength` 20；
- `carrier`：`enum` 是 `["sf", "zto", "yto"]`；
- `required` 正好是 `["number", "carrier"]`。

**两个容易踩的点**

- `unit` 别抄进 `required`：有默认值的参数被标成必填，模型会每次都硬编一个值。
- `minLength` / `maxLength` 是 JSON Schema 的固定拼法（驼峰），
  不是 `min_length`。

**验收会检查什么**：两个 schema 的 `properties`、`type`、`enum`、`required`
逐项核对。第 1 题（改错题）要跑模型看 `arguments` 的类型，验收里跑不了，
所以不在检查范围内。
