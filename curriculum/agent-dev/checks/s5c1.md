## 这一章的项目：把对话砍到只剩两句

在 `main.py` 里写一个函数：

```python
def trim_conversation(messages: list[dict]) -> list[dict]:
    ...
```

输入是 `[{"role": "user"|"assistant", "content": "..."}]`，输出也是同样形状的列表。

**规则**（正文「动手练」第 1 题）

只留两条：

1. **user 的第一句需求**——不是第一句，是第一句**需求**。`"你好"`、`"谢谢"`
   都算寒暄，要跳过；
2. **assistant 的第一个代码块**——含 ``` 的那条。

输入 `[你好, 你好！请问…, 我有个 Python 脚本…, 推荐用 PyYAML…, 能给个例子吗？, ```代码```, 谢谢！]`
应该正好输出 2 条：那句 YAML 需求 + 那段代码。

**两个容易踩的点**

- 不要在 `for` 里 `messages.remove(m)`：那会把传进来的列表改掉，同一个函数
  第二次跑结果就变了。用一个新的 `kept = []` 装结果。
- 不要在函数里存模块级变量（比如 `count = 0` 放外面）：验收会连续调用两次，
  结果必须一样。

**验收会检查什么**：条数是 2、第一条是那句需求、第二条是代码块、
传进去的列表没被改、两次调用结果一致。
