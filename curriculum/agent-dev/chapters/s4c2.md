# 第 12 章 什么时候该停下：别转圈

## 这一章要解决什么

你让它查“上海明天几点日落”，它调一次天气 API 就答出来了；  
你让它查“火星明天热不热”，它试完天气 API，又去搜 NASA，再翻维基百科……最后编了个 23℃ 的答案。

它不知道什么叫“查不到”，只觉得“还没猜对”。

这一章要把这个死循环拆掉。它不是没脑子，是没人告诉它：**猜不出来就停手，说‘没查到’比瞎猜强十倍**。

## 核心概念

### 终止信号得是模型能看懂的词  
别写“请停止推理”，它听不懂。要写“已拿到答案”“查不到就放弃”——这些是它训练时见过的、能当 token 输出的短语。它靠这个字串判断：“哦，这轮该收尾了。”

### 循环里得有人盯着它喊停  
你写的 while True 不会自己断。必须在每次拿到模型回复后，检查里面有没有终止信号（比如是否含“已拿到答案”），有就 break，不发下一轮请求。

### “不知道”是合法答案，不是失败  
模型怕输。你没给它兜底句式，它宁可胡诌“火星气象局官网显示……”。加一句“若无可靠来源，请直接回答‘查不到’”，它真会照做——前提是 prompt 里写了，代码里也接住了。

## 先跑起来

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

def ask_with_stop(prompt):
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.3,
        max_tokens=200,
        logprobs=True,
        top_logprobs=1
    )
    msg = response.choices[0].message.content.strip()
    print("模型说：", repr(msg))
    return msg

# 试试这个 prompt —— 明确给了终止指令
prompt = """你是一个严谨的资料助手。
查不到确切信息时，请直接回答“查不到”，不要推测、不要编造。
现在请回答：火星明天的气温是多少摄氏度？
请严格按以下格式结尾：
- 若有答案，结尾写“已拿到答案”
- 若无答案，结尾写“查不到就放弃”"""

answer = ask_with_stop(prompt)
```

运行后你会看到类似这样的输出：  
`模型说： '查不到就放弃'`  
或者（如果它没听话）：`'查不到'`  
注意：它可能不完全按你写的结尾词来，但只要出现“查不到”或“放弃”，说明终止意识已激活——下一节我们教你怎么在代码里抓住它。

## 动手练

1. **改上一章的天气 Agent**：在它的 system prompt 最后加一行：“若城市名无效或无天气数据，请直接回答‘查不到’，并以‘查不到就放弃’结尾。”  
   ✅ 做完标志：问“火星天气”，它输出里必须含“查不到”且不再调用天气 API。

2. **加终止检测逻辑**：在 Agent 的主循环里，每次拿到 `response.choices[0].message.content` 后，加一行 `if "查不到就放弃" in content or "已拿到答案" in content: break`。  
   ✅ 做完标志：运行“火星天气”时，只发 1 次 API 请求（用 `print("调用 API")` 验证），之后立刻退出循环。

3. **强制它认输**：把 prompt 改成：“请只回答一个词：要么是温度数字，要么是‘查不到’。结尾不加任何其他字。”  
   ✅ 做完标志：输出必须是纯 `'查不到'`（无空格、无标点、无换行），用 `len(answer) == 4 and answer == "查不到"` 能判对。

## 自测

<details><summary>1. 如果 prompt 里写“请不要继续思考”，但没给具体终止词，Agent 会停下吗？</summary>
不会。模型不理解“不要继续思考”这种抽象指令。“已拿到答案”才是它见过的、能作为生成终点的 token 序列。
</details>

<details><summary>2. 下面代码有没有问题？</summary>
```python
if "查不到" in response.choices[0].message.content:
    break
```
有问题。它可能输出“查不到火星数据”，但你只检查“查不到”，会误判。应检查明确的终止短语（如“查不到就放弃”），避免匹配到中间词。
</details>

<details><summary>3. 为什么不能只靠 temperature=0 来防止瞎猜？</summary>
temperature=0 只让输出更确定，不改变模型“必须给出答案”的默认倾向。它仍会编一个看似合理的数字——除非 prompt 明确授权它说“查不到”。
</details>
