# 第 18 章 切片别把句子砍成两半

## 这一章要解决什么

你让模型查资料：“把《三体》里关于‘宇宙社会学’的原文摘出来”。  
它翻完 PDF，切了一堆 512 字的块，扔进去问——结果返回：“宇宙是……黑暗森林……（截断）”“……中每个文明都是带枪的猎人（开头缺主语）”。

不是模型不行，是你喂给它的文本被砍在了半句话上。  
**句子被劈开，语义就散了。模型看不到完整主谓宾，自然答不准。**  
就像你读到“他拿起刀，准备——”，后面没了，你也不知道他要切菜还是切西瓜。

这一章就干一件事：**让切片尊重中文句子的呼吸感**——在哪停顿，就在哪切。

---

## 核心概念

### 句子是语义最小完整单元  
不是“字数差不多就行”，而是“有开头、有动作、有结尾”。中文靠标点收束：句号、问号、感叹号、省略号（……）是明确句尾；分号、冒号、逗号不算。  
你让模型总结一段话，它得看到“因为……所以……”才敢下结论；切在“因为”后面，它就只能瞎猜。

### 切片 ≠ 分段，更不是按字数硬砍  
`text[i:i+512]` 看似简单，但很可能把“这个方案可行，但需要验证——”切成两半。后半段丢了“但需要验证”，模型以为这是个肯定句，直接照抄。

### 中文标点不能靠正则随便匹配  
`re.split(r'[。？！]', text)` 会把“等等。”、“啊？！”、“……”里的省略号拆成三个点，漏掉句尾；也会把“第123.456章”里的小数点当句号。  
得用能识别中文标点边界的工具，或者写清楚规则：只认独立出现的句末标点。

---

## 先跑起来

```python
import re
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

def split_by_sentence(text):
    # 匹配中文句末标点：。？！……（注意省略号是两个字符，但实际常为一个Unicode）
    # 先统一处理省略号为单个字符 U+2026
    text = re.sub(r'\.{2,}', '…', text)
    # 在句末标点后切，保留标点
    parts = re.split(r'([。？！…])', text)
    sentences = []
    for i in range(0, len(parts), 2):
        if i + 1 < len(parts):
            sentences.append(parts[i] + parts[i + 1])
        elif parts[i].strip():
            sentences.append(parts[i].strip())
    return [s for s in sentences if s.strip()]

# 测试文本（复制粘贴就能跑）
test_text = "今天天气不错。你想喝咖啡吗？当然可以！不过……得先关掉那个弹窗。"
print(split_by_sentence(test_text))
```

运行后你会看到：
```
['今天天气不错。', '你想喝咖啡吗？', '当然可以！', '不过……得先关掉那个弹窗。']
```
每项都以句末标点结尾，且不截断任何一句话。这就是我们想要的“呼吸点”。

## 动手练

1. **改切分函数**：把上面 `split_by_sentence` 改成支持「分号」和「冒号」后也切（仅当它们独立成句时，比如“实验步骤如下：”之后换行，但“价格：12元”不算）。  
　✅ 做完标准：输入 `"第一步：打开电源；第二步：按下启动键。"` → 输出 `["第一步：", "打开电源；", "第二步：", "按下启动键。"]`（提示：先找带空格/换行的分号/冒号）

2. **验证完整性**：写一个函数 `is_complete_sentence(s)`，对每个切出来的句子返回 `True`（如含句末标点且非空），否则 `False`。  
　✅ 做完标准：`is_complete_sentence("你好")` → `False`；`is_complete_sentence("你好！")` → `True`

3. **实战切文档**：下载任意一篇中文新闻（如新华社短讯），用你写的函数切分，保存为 `sentences.json`，每行一个句子（用 `json.dump(..., indent=2)`）。  
　✅ 做完标准：文件打开后是清晰的 JSON 数组，无乱码，无跨行断裂句。

## 自测

<details><summary>1. 下面哪句切分破坏了语义？</summary>
A. `"请检查代码：if x > 0: print('ok')"` → `["请检查代码：", "if x > 0: print('ok')"]`  
B. `"系统启动失败。原因未知。"` → `["系统启动失败。", "原因未知。"]`  
C. `"用户输入：'hello'，程序返回：'world'。"` → `["用户输入：", "'hello'，程序返回：", "'world'。"]`  
**答案：C**（“'hello'，程序返回：'world'。” 是一个完整陈述，冒号前后不是独立句子）
</details>

<details><summary>2. 为什么不能直接用 text.split('。')？</summary>
**答案：会丢掉句号本身；无法处理问号、感叹号；会把“第1.5节”里的小数点误切。**
</details>

<details><summary>3. 如果你切完喂给模型，它仍答错，可能是什么原因？（至少写一个）</summary>
**答案：句子虽完整，但上下文被切断了（如前一句是“因为A”，后一句是“所以B”，但两句被分到不同 chunk）。这时候需要重叠切片或加前缀。**
</details>
