# 第 32 章 算清楚每句话花多少钱

## 这一章要解决什么

你让模型帮你把一段 Python 代码改成异步版本，它秒回；你顺手加一句“顺便解释下 asyncio.run 和 asyncio.run_coroutine_threadsafe 的区别”，它又秒回。

你心里一喜：这玩意儿真能干活！

直到月底账单弹出来——咦？这个月光是改代码就花了 12 块？你根本没发几条消息啊。

这一章就干一件事：**看清楚钱是怎么花出去的**。不是靠猜，不是靠估，是拿 tokenizer 切开每句话，数清每个 token，再按官网价表算出真实花费。

不搞虚的。你改一行代码，它多吐 50 个字，你就得多付几分钱——这事得看得见、算得清。

---

## 核心概念

### Token 不是字，也不是词，是“最小可识别单元”

中文里一个字常是一个 token，但“Transformer”会被切成 `['Trans', 'former']`，`"don't"` 可能变成 `['do', "n't"]`。  
为什么需要它？因为模型内部只认 token 编号，不认汉字或英文单词。价格也是按 token 算的，不是按字或按句。

### 输入 token + 输出 token = 总花费

你发一条消息，模型要先“读”你的话（输入 token），再“写”回答（输出 token）。  
API 返回里有 `usage.input_tokens` 和 `usage.output_tokens` —— 这俩加起来，才是你钱包真正出血的地方。

### 模型不同，价格和切分方式都不同

GPT-4 和 Claude-3 用的 tokenizer 完全不一样。同一段话，GPT-4 算 87 个 token，Claude-3 可能算 93 个。  
价格也差得远：GPT-4-turbo 输入 1M token 收 $10，Claude-3-haiku 同样输入只要 $0.25。  
不比，你永远不知道换模型是不是真省钱。

## 先跑起来

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "把这段代码改成用 requests.post 发送 JSON：\nimport urllib.request\nurllib.request.urlopen('https://api.example.com')"}],
    temperature=0.3,
)

print("输入 token 数：", response.usage.prompt_tokens)
print("输出 token 数：", response.usage.completion_tokens)
print("总 token 数：", response.usage.total_tokens)
```

运行后你会看到三行数字，比如：
```
输入 token 数： 42
输出 token 数： 68
总 token 数： 110
```

注意：如果你用的是 Claude，这段代码会报错（因为不是 OpenAI 接口）——**先别管它，下一节我们专门处理多模型对比**。

## 自测

<details><summary>1. 如果我把 temperature 从 0 调到 1，token 数会怎么变？</summary>
输出 token 数通常会增加（模型生成更长、更发散的回答），输入 token 数不变（你发的话没变）。但不是绝对——如果高温导致它早停，也可能变短。
</details>

<details><summary>2. 下面这行代码有没有问题？为什么？</summary>
```python
response.usage.input_tokens  # ← 这里
```
有问题。`response.usage` 是 `CompletionUsage` 对象，但 `input_tokens` 字段名在 openai>=1.0 中叫 `prompt_tokens`。写 `input_tokens` 会报 `AttributeError`。
</details>

<details><summary>3. 我用 tokenizer 把一句话切出来 100 个 token，API 返回 total_tokens=105。多出来的 5 个最可能是什么？</summary>
是系统提示词（system message）或工具描述（tools）里的 token。即使你没显式写 system，SDK 可能自动加了默认角色描述；如果用了 function calling，schema 也会算进去。
</details>
