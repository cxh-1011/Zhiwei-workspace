# 第 27 章 规则判分和模型判分怎么选

## 这一章要解决什么

你让模型给一段会议纪要打分：“是否覆盖了三个关键结论？”  
它回了个 8/10，还写了句“逻辑清晰但漏了第三点”。  
你心里一喜——等等，它真知道哪三点是“关键”吗？还是 just guessing？

上一章你刚让它跑通了自动改代码、查资料的流程。现在它开始“做判断”了：  
✅ 判日期格式对不对（`2024-03-15` vs `15/03/2024`）  
✅ 判用户说的“再便宜点”是不是砍价话术  
✅ 判摘要里有没有提到“甲方要求下周三前交付”  

——这些判断，**什么时候写一行正则就完事，什么时候非得拉大模型来猜？**  
这一章不讲理论，只给你两把尺子：一把量「规则明不明确」，一把量「标准在不在模型脑子里」。

---

## 核心概念

### 规则判分：当答案能用“是/否/数字”穷举出来  
比如日期格式：合法的只有几种写法（`YYYY-MM-DD`、`YYYY/MM/DD`、带中文“年月日”的），错的千奇百怪。  
你写个正则，匹配上就是对，不匹配就是错。它不猜，不犹豫，不编。

### 模型判分：当人自己都得想一想“算不算”  
比如摘要质量：“是否覆盖要点”——要点在哪？谁定的？模型没见过原始会议录音，但它读过千万份带评语的摘要。  
它不是查表，是类比：这个摘要，像不像它见过的“8分摘要”？

### 关键分水岭：看“错例能不能列全”  
✔️ 能列全（如：日期里出现字母、月份>12、少位数）→ 上正则  
❌ 列不全（如：“语气太生硬”“没突出风险”“感觉不像人写的”）→ 上模型  

别被“看起来高级”骗了。模型打分不是更准，只是更“敢模糊”。

## 先跑起来

```python
import os
import re
from openai import OpenAI

client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))

# 规则判分：检查日期格式（只认 YYYY-MM-DD）
def is_valid_date(text):
    return bool(re.fullmatch(r"\d{4}-\d{2}-\d{2}", text))

# 模型判分：问模型“这段摘要覆盖要点了吗？1~5分”
def score_summary(summary: str) -> int:
    resp = client.chat.completions.create(
        model="gpt-4o",
        messages=[{
            "role": "user",
            "content": f"请给以下摘要打1~5分，标准：是否覆盖原文三个关键结论。\n\n摘要：{summary}\n\n只返回一个数字，不要解释。"
        }],
        temperature=0.0,
        max_tokens=2
    )
    try:
        return int(resp.choices[0].message.content.strip())
    except:
        return 0  # 报错就返0，方便你发现异常

# 测试
print("规则判分:", is_valid_date("2024-03-15"), is_valid_date("15-03-2024"))
print("模型判分:", score_summary("项目延期，预算超支，需重签合同。"))
```

运行后你会看到：  
- 第一行输出 `True False`（正则立刻给出确定结果）  
- 第二行输出一个 `1`~`5` 的数字（可能卡顿1秒，且偶尔返回非数字——这就是模型的“不确定”）

## 自测

<details><summary>1. 下面哪个场景更适合规则判分？</summary>
A. 判断用户消息是否含紧急词（“马上”“立刻”“爆炸”）  
B. 判断用户情绪是“焦虑”还是“兴奋”  
C. 判断代码片段是否能被 Python 解释器成功 import  
D. 判断摘要是否“有说服力”  
→ 答案：A 和 C。A 可枚举关键词；C 有明确语法定义。B 和 D 主观、边界模糊，需模型。
</details>

<details><summary>2. 为什么 `temperature=0.0` 在打分时很重要？</summary>
因为打分需要确定性输出。temperature 越高，模型越爱“发挥”，同一摘要可能这次打4分、下次打2分。设为 0.0 强制它选概率最高的那个数字。
</details>

<details><summary>3. 如果 `score_summary` 总是返回 `0`，最可能的原因是？</summary>
模型返回了非数字文本（比如“我认为是4分”）。代码里 `int(...)` 失败后进 except 分支，强制返回 0。你应该先 print 出原始 content 看一眼。
</details>
